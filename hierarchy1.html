Young Serif + Figtree in a Major Second (1.125)

Base 1.125rem (18px) / Major second (1.125) / Sizes from Type Scale

Two typefaces: Young Serif, a chunky storybook serif, for the headings and Figtree, a friendly variable sans, for reading. The serif-vs-sans contrast separates headings from text even where the size steps are small.

Every quest starts with a title card

Young Serif carries the big moments on this page. Its heavy, rounded serifs feel like the cover of a well-loved storybook, which keeps the hierarchy playful without tipping into a cartoon.

font-family: "Young Serif", serif;
font-size: 1.802rem; /* 28.83px */
font-weight: 400;
line-height: 1.15;

Chapters need a clear signpost

The second level still uses the serif, one step smaller on the scale. A major second is a gentle ratio, so each heading also gets generous space above it to make the jump between levels easy to see.

font-family: "Young Serif", serif;
font-size: 1.602rem; /* 25.63px */
font-weight: 400;
line-height: 1.15;

Side quests sit one step down

Young Serif comes in a single weight, so contrast here comes from size, spacing and color instead of bold. Fewer tools keeps the page calm.

font-family: "Young Serif", serif;
font-size: 1.424rem; /* 22.78px */
font-weight: 400;
line-height: 1.15;

Item descriptions stay compact

The smallest heading is only a little larger than the body text, so it takes on the teal accent and the switch from serif to sans does the rest.

font-family: "Young Serif", serif;
font-size: 1.266rem; /* 20.25px */
font-weight: 400;
color: #0b6457;

Body text

Figtree handles all the reading on this page. It is a clean geometric sans by Erik Kennedy with round, friendly letters and a generous x-height. At 18px with a 1.45 line height it stays comfortable next to the much heavier serif, and lines stop at about 65 characters.

font-family: "Figtree", sans-serif;
font-size: 1.125rem; /* 18px */
font-weight: 400;
line-height: 1.45;
max-width: 65ch;

Emphasis

When something matters, it changes color instead of slanting. Young Serif has no italic, so emphasis uses a magenta accent and a heavier Figtree weight rather than a faked slant.

font-family: "Figtree", sans-serif;
font-size: 1.125rem;
font-weight: 600;
font-style: normal;
color: #c21e63;

Link

Links get their own teal color and pick up an underline on hover, like this link to Young Serif on Google Fonts.

font-family: "Figtree", sans-serif;
font-size: 1.125rem;
font-weight: 600;
color: #0b6457;
text-decoration: underline on hover;
