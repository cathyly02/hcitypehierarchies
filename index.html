Type Hierarchies

Three web type hierarchies built with Bootstrap and Google Fonts. Each page shows H1 through H4, body text, emphasis and links, with the CSS for every element beside it. The pages use three typefaces: Young Serif, Figtree (variable) and Big Shoulders (variable). Specs are set in Red Hat Mono, also variable.

About the modular scale

A modular scale starts with a base size for body text and multiplies it by the same ratio for each step up. All three pages use a major second (1.125) on an 18px base, calculated with Type Scale.

A major second is a gentle scale, so the headings feel like part of the reading rather than posters. The tradeoff is that H4 is only about 2px larger than body text, so each page separates the levels with something besides size: typeface contrast on Hierarchy 1, variable weight and optical size on Hierarchy 2, and weight and color on Hierarchy 3.
