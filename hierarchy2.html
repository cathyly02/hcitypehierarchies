Big Shoulders in a Major Second (1.125)

Base 1.125rem (18px) / Major second (1.125) / Sizes from Type Scale

One variable typeface for everything. Big Shoulders' weight axis (100 to 900) and optical size axis (10 to 72) do the work a second typeface usually would.

A typeface built for the city

Big Shoulders was made for Chicago, with tall, condensed letters that echo the signs and buildings around the Loop. This page uses it for everything, from the headlines down to the paragraphs.

font-family: "Big Shoulders", sans-serif;
font-size: 1.802rem; /* 28.83px */
font-variation-settings:
  "wght" 800, "opsz" 72;
line-height: 1.1;

One family, two jobs

The optical size axis is what makes a single typeface work here. At headline sizes the letters run tight and dramatic, and at reading sizes the same family opens up so paragraphs stay comfortable.

font-family: "Big Shoulders", sans-serif;
font-size: 1.602rem; /* 25.63px */
font-variation-settings:
  "wght" 750, "opsz" 72;
line-height: 1.1;

Weight does the heavy lifting

With a weight axis that runs from 100 to 900, each heading level gets its own weight instead of a second typeface. The headings on this page step down from 800 to 650.

font-family: "Big Shoulders", sans-serif;
font-size: 1.424rem; /* 22.78px */
font-variation-settings:
  "wght" 700, "opsz" 48;
line-height: 1.1;

Small headings stay loud

At the fourth level the size difference from body text is slight, so the flag-red color keeps it from blending into the paragraph below.

font-family: "Big Shoulders", sans-serif;
font-size: 1.266rem; /* 20.25px */
font-variation-settings:
  "wght" 650, "opsz" 36;
color: #c8102e;

Body text

Body text sits at 18px with optical sizing set to auto, so the browser picks the text-friendly version of the letters. Condensed type fits more words on each line, which makes the 65-character limit matter even more on this page.

font-family: "Big Shoulders", sans-serif;
font-size: 1.125rem; /* 18px */
font-weight: 400;
font-optical-sizing: auto;
line-height: 1.45;

Emphasis

Emphasis turns flag red and picks up a little extra weight, borrowing the red from the stars on the Chicago flag.

font-family: "Big Shoulders", sans-serif;
font-size: 1.125rem;
font-weight: 700;
font-style: normal;
color: #c8102e;

Link

Links are lake blue and underline on hover, like this link to Big Shoulders on Google Fonts.

font-family: "Big Shoulders", sans-serif;
font-size: 1.125rem;
font-weight: 700;
color: #0b6fa4;
text-decoration: underline on hover;
