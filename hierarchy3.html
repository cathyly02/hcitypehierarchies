Figtree in a Major Second (1.125)

Base 1.125rem (18px) / Major second (1.125) / Sizes from Type Scale

One variable sans serif. With no second typeface to lean on, the hierarchy comes from weight (800 down to 400), size and color.

One typeface, a full range of voices

Figtree is a variable typeface with weights from light to black. This page uses only Figtree, so every level of the hierarchy comes from weight, size and color.

font-family: "Figtree", sans-serif;
font-size: 1.802rem; /* 28.83px */
font-weight: 800;
line-height: 1.15;

Friendly shapes for screens

Round letters and a large x-height make Figtree feel approachable, the way a good game menu does. It stays crisp at small sizes on a phone.

font-family: "Figtree", sans-serif;
font-size: 1.602rem; /* 25.63px */
font-weight: 750;
line-height: 1.15;

Weight replaces a second typeface

With no serif to contrast against, the headings lean on heavier weights. The first level sits at 800 and each level below steps down.

font-family: "Figtree", sans-serif;
font-size: 1.424rem; /* 22.78px */
font-weight: 700;
line-height: 1.15;

Spacing and color for the smallest heading

The fourth level adds a touch of letter-spacing and the violet accent so it reads as a heading rather than a bolded sentence.

font-family: "Figtree", sans-serif;
font-size: 1.266rem; /* 20.25px */
font-weight: 700;
letter-spacing: 0.02em;
color: #6c4bff;

Body text

Body text uses weight 400 at 18px with a 1.45 line height. The same typeface at four different weights is enough to build a clear hierarchy without the page feeling flat.

font-family: "Figtree", sans-serif;
font-size: 1.125rem; /* 18px */
font-weight: 400;
line-height: 1.45;
max-width: 65ch;

Emphasis

Emphasis switches to violet at weight 600. Figtree does have a true italic, but color keeps emphasis consistent across all three pages.

font-family: "Figtree", sans-serif;
font-size: 1.125rem;
font-weight: 600;
font-style: normal;
color: #6c4bff;

Link

Links are rust colored and underline on hover, like this link to Figtree on Google Fonts.

font-family: "Figtree", sans-serif;
font-size: 1.125rem;
font-weight: 600;
color: #b4380f;
text-decoration: underline on hover;
